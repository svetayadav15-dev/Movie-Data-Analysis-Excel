# Movie-Data-Analysis-Excel
Excel dashboard project with data cleaning, pivot tables, KPIs, charts, and insights.
# &#x20;                           **IMDb Movie Dataset Analysis**

### 📌 Project Overview



**This project analyzes the IMDb Movie Dataset using Microsoft Excel. The dataset was cleaned, transformed, and analyzed to discover trends in movie production, genres, directors, certifications, audience votes, and box office performance.**

### 

### 🎯 Objectives

**Clean and prepare the raw movie dataset.**

**Analyze movie trends using Pivot Tables.**

**Create an interactive dashboard.**

**Generate meaningful business insights.**

### 🛠️ Tools Used

**Microsoft Excel**

**Pivot Tables**

**Pivot Charts**

**Slicers**

**Data Cleaning**

**Dashboard Design**

### 📊 Dashboard Highlights



**The dashboard includes:**



**🎬 Movies by Year**

**🎭 Movies by Genre**

**📜 Movies by Certificate**

**🎥 Top 10 Directors**

**⭐ Top 10 Most Voted Movies**

**💰 Top 10 Highest Grossing Movies**

### 🔍 Key Insights

**Movie production increased significantly after 2000.**

**Drama is the most common genre in the dataset.**

**Most movies are rated R and PG-13.**

**The Shawshank Redemption received the highest audience votes.**

**Star Wars: Episode VII – The Force Awakens generated the highest gross revenue.**

**Top directors have consistently contributed to the movie industry.**
